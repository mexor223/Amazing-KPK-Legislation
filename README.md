# Amazing KPK — Законодательство

Репозиторий нормативных документов для приложения «КПК» (Amazing Online).

## Структура

- `manifest.json` — каталог документов, который читает КПК.
- `documents/` — тексты документов в Markdown.
- Каждый документ хранится отдельным файлом; КПК скачивает их и сохраняет локально для офлайн-чтения.

## Добавление документа

1. Создайте Markdown-файл в `documents/`.
2. Добавьте запись в массив `documents` файла `manifest.json`.
3. Укажите название, имя файла и прямую ссылку на raw-файл GitHub.
4. После обновления репозитория КПК сможет синхронизировать каталог.

## Источники и актуальность

Для каждого документа указывайте первоисточник, дату редакции и дату последней проверки. Не заменяйте оригинальный текст пересказом. Изменения в нормативных текстах следует сверять с первоисточником.
